# Release checklist

Before publishing this directory:

- replace the placeholder author and paper metadata in `CITATION.cff`;
- confirm that the selected repository license is compatible with any retained
  code derived from SIREN/Meta-INR implementations;
- add the final paper title, authors, DOI, and repository URL to `README.md`;
- decide whether to publish a trained initialization checkpoint separately;
- verify that no experiment logs, field data, credentials, or private paths are
  present in the release commit.
