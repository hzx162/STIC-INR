# depthCharge3D

The case uses `compressibleInterFoam` with a structured mesh generated by
`blockMesh`. Initial pressure, temperature, and phase regions are defined by
`system/setFieldsDict`. The `fieldsToSmartRedis` function object in
`system/controlDict` publishes the internal pressure field at each write time.

Case preparation follows the sequence in `Allrun`:

```text
blockMesh -> restore0Dir -> setFields -> decomposePar
```
